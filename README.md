# Очередь машин на отгрузку

Консольная программа на Python для склада: хранит очередь машин на отгрузку, принимает новые заявки водителей, проверяет их и показывает, кто за кем едет. Данные сохраняются в текстовый файл, поэтому после закрытия программы очередь не теряется.

Это мой первый учебный проект. Идея взята из реальной работы на складе.

## Возможности

- Показать всю очередь, отсортированную по времени
- Узнать позицию машины в очереди по госномеру
- Узнать, кто следующий после заданного времени
- Добавить новую заявку (с проверкой формата, времени и дублей)
- Удалить заявку по номеру машины
- Автоматическая очистка данных: лишние пробелы убираются, номера приводятся к верхнему регистру (`" а123вс "` и `"А123ВС"` считаются одним номером)

## Требования

- Python 3.8 или новее
- Сторонние библиотеки не нужны

## Запуск

1. Скачайте `queue.py` и `requests.txt` и положите в одну папку.
2. Запустите программу:

```
python queue.py
```

Если файла `requests.txt` нет, программа стартует с пустой очередью и создаст файл при добавлении первой заявки.

## Формат данных

Каждая заявка это одна строка в файле `requests.txt`:

```
Фамилия;госномер;время
```

Время записывается строго в формате `ЧЧ:ММ` с нулём впереди (например, `09:15`, а не `9:15`).

Пример `requests.txt`:

```
Петров;а123вс;14:30
Иванов;К777НО;09:15
Сидоров;м555тт;11:00
```

## Команды

| Команда | Что делает |
|---------|------------|
| `1` | Позиция машины в очереди по номеру |
| `2` | Кто следующий после указанного времени |
| `3` | Показать всю очередь |
| `4` | Добавить нового водителя |
| `5` | Удалить водителя из очереди |
| `выход` | Выйти из программы (или из подменю) |

Пример вывода команды `3`:

```
1. 09:15 Иванов К777НО
2. 11:00 Сидоров М555ТТ
3. 14:30 Петров А123ВС
```

## Как это устроено

В коде несколько небольших функций, каждая делает одно дело:

- `load_requests` читает заявки из файла
- `parse_request` разбирает и очищает одну заявку
- `build_queue` собирает очередь и сортирует её по времени
- `format_queue` оформляет очередь в читаемый текст
- `find_position`, `next_car` ищут машину по номеру и по времени
- `is_valid_time` проверяет, что время записано как `ЧЧ:ММ`
- `remove_request` убирает заявку из списка
